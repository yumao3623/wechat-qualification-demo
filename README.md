# 企业政府资质预评估微信小程序 Demo

一个面向企业资质申报前准备的微信小程序 Demo，可在约 1 分钟内完成企业信息整理与四类政府资质的初步评估。

## 项目简介

项目覆盖高新技术企业、科技型中小企业、专精特新和雏鹰企业四类资质。系统基于虚构的 Mock 企业公开画像识别关键信息缺口，再结合用户补充的经营数据生成可解释的预评估结果、判断证据、缺口与行动建议，并提供顾问咨询入口。

当前项目定位为本地可运行的 Demo。评估结果仅用于初步判断和申报准备参考，不代表政府官方认定，也不承诺资质或补贴结果。

## 核心功能

- 企业搜索与主体确认：从虚构 Demo 企业中检索并核对目标主体。
- 企业画像：汇总企业基本信息、经营指标及数据来源。
- 动态补充经营数据：仅展示当前评估所需的缺失字段。
- 四类资质预评估：通过独立规则引擎统一生成结构化结果。
- 可解释报告：展示判断条件、实际数据、证据来源和人工核验项。
- 报告记录：查看进行中、已完成或失败的历史诊断。
- 顾问咨询：提交进一步申报咨询需求。

## 产品流程

首页 → 企业搜索 → 主体确认 → 企业画像 → 动态补数 → 发起诊断 → 诊断报告 → 证据链 / 缺口行动 → 顾问咨询

游客可先完成企业选择和数据准备，在发起诊断或查看历史报告时进入协议与会话流程。

## 技术实现

```text
原生微信小程序
    │
    │ REST API
    ▼
Node.js + Express
    ├── MockEnterpriseProvider：虚构企业数据
    ├── QualificationEngine：四类资质规则
    └── JSON Repository：Demo 运行数据
```

- 前端：原生微信小程序、WXML、WXSS、JavaScript。
- 后端：Node.js 20+、Express 5、REST API。
- 业务层：`MockEnterpriseProvider`、`QualificationEngine` 和四个独立 Evaluator。
- 数据层：虚构企业 fixture 与可替换的 JSON Repository。
- 测试：Node.js 内置 test runner，覆盖单元测试与 API 集成测试。

主要目录：

| 目录                      | 内容                             |
| ----------------------- | ------------------------------ |
| `miniprogram/`          | 微信小程序页面、组件与前端服务                |
| `server/src/`           | REST API、业务服务、规则引擎与 Repository |
| `server/data/fixtures/` | 虚构 Mock 企业数据                   |
| `tests/`                | 单元测试与 API 集成测试                 |
| `docs/`                 | 产品、设计、架构、测试与决策文档               |

完整技术设计与接口契约见 [技术架构](docs/architecture.md)。

## 快速运行

### 1. 环境要求

- Node.js 20 或更高版本
- npm
- 微信开发者工具

### 2. 安装并启动后端

在项目根目录执行：

```bash
npm install
npm start
```

默认服务地址为 `http://127.0.0.1:3000`。可访问 `http://127.0.0.1:3000/api/health` 检查服务状态。

Windows PowerShell 如因执行策略无法运行 `npm`，可改用：

```powershell
npm.cmd install
npm.cmd start
```

### 3. 导入微信开发者工具

1. 打开微信开发者工具并选择“导入项目”。
2. 项目目录选择本仓库根目录。
3. 保持后端服务运行，编译并打开小程序。

项目默认提供 Demo 评审模式，无需企查查 API Key、微信 AppSecret 或数据库即可运行核心流程。可选的后端环境变量见 [.env.example](.env.example)。真实微信身份认证不属于本 Demo 的生产能力范围。

## 推荐体验

首次体验可搜索 `Demo`，推荐选择 **杭州市云舟微研 Demo 有限公司**。该场景能够完整展示：企业画像 → 缺失数据识别 → 动态补充经营数据 → 诊断 → 四类资质报告 → 证据链 → 缺口与行动。

| Demo 企业           | 主要展示场景            |
| ----------------- | ----------------- |
| 杭州市星澜智造 Demo 有限公司 | 数据较完整，展示较积极的预评估结果 |
| 杭州市云舟微研 Demo 有限公司 | 识别缺失信息并动态补数       |
| 杭州市青禾商贸 Demo 有限公司 | 多项关键指标暂不满足        |
| 宁波市远汐数科 Demo 有限公司 | 杭州区域资质不适用         |

全部企业均为虚构 Demo 数据，不是企查查真实数据。

## 已知限制

- 当前使用虚构 Mock 企业数据，没有接入真实企查查 API。
- 评估规则为 Demo 简化实现，结果不代表政府官方认定。
- 用户补充的经营数据属于自主声明，未经审计或官方核验。
- “雏鹰企业”当前以杭州“新雏鹰”政策作为区域示例。

当前项目聚焦本地可运行 Demo，真实企业数据接入、生产微信认证及正式数据基础设施不在当前 Demo 范围内。
