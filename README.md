# 企业政府资质预评估微信小程序 Demo

> 当前状态：Phase 1（产品、政策、接口与测试规格）已完成；尚未进入工程实现。  
> 当前仓库不能启动后端或导入可运行小程序，测试均为 `NOT EXECUTED`。请勿把文档完成理解为 Demo 已完成。

## 项目简介

本项目计划实现一个招聘能力验证用微信小程序 Demo：结合虚构企业公开画像和用户主动补充的经营数据，在约 1 分钟内对高新技术企业、科技型中小企业、专精特新中小企业和“雏鹰企业（杭州新雏鹰区域示例）”进行可解释预评估。

本工具不是政府官方认定系统，不保证企业符合资质或获得补贴。

## 产品目标

- 游客先完成搜索、主体确认、画像和动态补数。
- 用户明确同意协议后才登录并发起诊断。
- 输出四类资质的准备度、证据、缺口与行动。
- 不可可靠自动判断的规则明确标记人工核验。
- 无真实企业 API Key 或微信 AppSecret 时仍能使用虚构 Mock 完整演示。

## 计划技术架构

- 小程序：原生 WXML、WXSS、JavaScript、微信官方 API。
- 后端：Node.js 20 LTS、Express、REST。
- 数据：通过 Repository 隔离的本地 JSON（仅 Demo 单进程）。
- 企业数据：默认 `MockEnterpriseProvider`，未来预留正式授权 API Provider。
- 规则：独立 `QualificationEngine` 与四个 Evaluator。
- Admin：由同一 Express 进程提供的本地只读静态页面。

详细目录和契约见 `docs/architecture.md`。

## 计划完整演示流程

```text
游客首页 → 企业搜索 → 主体确认 → 企业画像 → 动态补数
→ 发起诊断 → 协议默认未勾选 → 明确同意 → wx.login / Demo Session
→ 诊断进度 → 四类报告 → 证据链 → 缺口与行动
→ 报告 Tab 回看 → 联系顾问
```

## 已知限制

- 当前只有规格文档，没有可运行产品。
- 政策核验时点为 2026-08-10，申报前必须复核当年通知和地区要求。
- 专精特新发展评价分依赖官方平台；Demo 不复算不可得的完整平台计算环境。
- 杭州“新雏鹰”只是区域示例，非全国统一资质。
- Demo Auth 不等于生产微信身份认证。
