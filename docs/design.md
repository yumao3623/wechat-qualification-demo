# 企业政府资质预评估微信小程序 Demo｜交互与界面设计规格

> 文档版本：v2.0
> 规格日期：2026-08-11

## 1. 设计目标

1. 用户能快速理解产品价值并完成企业数据准备。
2. 页面始终区分虚构公开画像、用户补充、系统推导和需人工核验的数据。
3. 结果强调准备度、缺口和下一步，不制造官方认定错觉。
4. 登录、协议和个人信息收集可预期、可拒绝。
5. Loading、Empty、Error、Success 状态均提供明确反馈和下一步操作。

## 2. 视觉方向

- 风格可信、克制、轻量，不仿冒政府官方界面，不使用奖章式“认证通过”表达。
- 深蓝和青色用于导航与主操作，橙色用于缺失或人工核验，红色仅用于错误或明确风险。
- 状态不能只依赖颜色，必须同时显示文字。
- 企业名称、政策名称和错误信息支持多行，不遮挡按钮或后续内容。
- Mock 模式在搜索、主体、画像和报告页持续显示“虚构 Demo 数据”。
- 关键页面显示免责声明：“本工具仅提供预评估，最终以主管部门政策、申报通知及审核结果为准。”

## 3. 导航与页面层级

```text
Tab：首页
  └─ 企业搜索
      └─ 主体确认
          └─ 企业画像
              └─ 补充经营数据（按需）
                  └─ 协议弹窗
                      └─ 诊断进度
                          └─ 诊断报告
                              ├─ 证据链
                              ├─ 缺口与行动
                              └─ 联系顾问

Tab：报告
  ├─ 未登录引导 / 协议弹窗
  ├─ 诊断进度
  └─ 诊断报告

Tab：我的
  ├─ 使用说明
  ├─ 隐私政策
  ├─ 用户协议
  ├─ 免责声明
  └─ 退出登录（仅已登录）
```

页面间只传企业、诊断或报告 ID。返回页面时重新读取必要状态，避免展示过期进度。

## 4. 通用组件

| 组件 | 用途 | 交互规则 |
| --- | --- | --- |
| 异步状态 | 承载加载、空、错误和成功内容 | 错误显示用户文案和请求编号，不显示内部堆栈 |
| Demo 标签 | 标识虚构企业数据 | 企业相关页面持续可见 |
| 数据来源标签 | 标识 Mock、用户补充、系统推导等来源 | 可同时显示统计期和观察时间 |
| 资质结果卡 | 展示资质状态、摘要和主要缺口 | 可进入证据或行动页 |
| 判断明细 | 展示条件、要求、实际值、来源和结果 | 缺失值显示“未提供” |
| 协议弹窗 | 展示三份法律文件和确认操作 | 每次打开复选框重置为未勾选 |
| 动态字段控件 | 按服务端字段定义渲染输入 | 显示单位、统计期、用途和行内错误 |
| 缺口行动卡 | 展示缺口、优先级、动作和材料 | 不使用承诺性文案 |

## 5. 状态与文案

### 5.1 资质状态

| 状态 | 展示文案 | 设计重点 |
| --- | --- | --- |
| `promising` | 较有希望 | 仍显示人工核验项和免责声明 |
| `opportunity` | 存在机会 | 强调尚需准备或核验 |
| `needs_data` | 需补充数据 | 指向缺失字段或证据 |
| `not_met` | 暂不满足 | 展示明确缺口和行动建议 |
| `not_applicable` | 不适用 | 说明地域、主体或规则日期原因 |

禁止出现“保证通过”“一定符合”“已获得资质”“官方认定通过”“保证获得补贴”。

### 5.2 通用四态

- Loading：显示正在执行的动作，禁用重复提交；长时间处理时提示仍在进行。
- Empty：解释内容为空的原因，并提供一个主要操作。
- Error：说明影响、数据是否保留和可执行的重试或返回操作。
- Success：展示完成结果和下一步，不夸大后台处理状态。

## 6. 页面状态总表

| 页面 | 登录 | Loading | Empty | Error | Success |
| --- | --- | --- | --- | --- | --- |
| 首页 | 免登录 | 核心静态内容直接展示 | 不适用 | 配置异常仍保留主入口 | 价值信息、四类介绍、开始按钮 |
| 企业搜索 | 免登录 | 正在搜索 Demo 企业 | 未找到匹配企业 | 请求失败并可重试 | 结果列表和 Demo 标签 |
| 主体确认 | 免登录 | 企业详情加载中 | 不适用 | 企业不可用，返回搜索 | 主体字段、确认和重选 |
| 企业画像 | 免登录 | 画像加载中 | 暂无可展示字段 | 加载失败并可重试 | 已知、缺失、待补充分区 |
| 补充经营数据 | 免登录 | 字段定义加载中 | 当前无补充项 | 校验或网络错误 | 保存成功并重新计算缺失项 |
| 协议弹窗 | 免登录 | 登录中或创建诊断中 | 不适用 | 明确说明未登录或未创建 | 创建成功进入进度页 |
| 诊断进度 | 已登录 | 等待或处理中 | 不适用 | 查询错误或诊断失败 | 报告完成入口 |
| 诊断报告 | 已登录 | 报告加载中 | 未完成时进入进度 | 无权限或加载失败 | 四类结果和明细入口 |
| 证据链 | 已登录 | 明细加载中 | 无证据按数据异常提示 | 加载失败并可重试 | 按资质展示判断项 |
| 缺口与行动 | 已登录 | 清单加载中 | 未发现明确缺口 | 加载失败并可重试 | 缺口和行动列表 |
| 报告 Tab | 保存数据需登录 | 报告列表加载中 | 已登录但无诊断 | 请求失败或诊断失败 | 进行中、完成等列表项 |
| 我的 Tab | 免登录 | 会话检查不阻塞法律入口 | 不适用 | 会话异常按游客展示 | 法律入口和条件退出 |
| 联系顾问 | 免登录 | 正在提交 | 不适用 | 字段或网络错误 | 咨询需求已提交 |
| 法律与帮助 | 免登录 | 内容加载中 | 内容缺失按错误处理 | 加载失败 | 标题、版本、日期和正文 |

## 7. 首页 Tab

页面从上到下展示：

1. 产品名称和“资质预评估 Demo”标识。
2. “约 1 分钟了解企业申报准备度”主标题和非官方认定说明。
3. “开始预评估”主按钮。
4. 高新技术企业、科技型中小企业、专精特新、杭州新雏鹰四类介绍。
5. 选企业、补关键数据、看证据与行动的三步说明。
6. 先体验、不自动登录、不强制手机号的隐私提示。
7. 免责声明。

点击主按钮直接进入企业搜索。进入或切回首页不触发登录、授权或协议弹窗。

## 8. 企业搜索

- 顶部显示“选择企业”流程位置。
- 搜索框提示输入虚构 Demo 企业名称关键词。
- 结果卡展示企业名称、Demo 编号、地区、行业、经营状态和 Demo 标签。
- 关键词为空或不足 2 个字符时显示字段提示。
- 新搜索结果覆盖旧结果，较早返回的请求不得覆盖较新的查询。
- 点击企业进入主体确认，不直接创建诊断。

## 9. 主体确认

- 标题为“请确认企业主体”。
- 展示名称、Demo 编号、法定代表人、成立日期、注册资本、地区、状态和行业。
- 主按钮“确认该企业”进入企业画像。
- 次操作“返回重新搜索”返回搜索页。
- 切换企业时重置当前流程上下文，不混用其他企业的补充数据。

## 10. 企业画像

- 顶部展示企业摘要和 Demo 标签。
- 内容分为已获取、缺失、需要补充或核验三组。
- 已获取字段同时展示值、单位、期间和来源。
- 需人工核验的项目使用单独提示，不伪装成普通数值必填项。
- 有动态字段时主按钮为“补充关键数据”；无动态字段时为“准备发起诊断”。

## 11. 动态补充经营数据

- 顶部文案为“仅询问当前判断缺少的数据”。
- 字段按企业规模、人员研发、收入财务、知识产权与资质、市场融资分组；空组不展示。
- 每个字段显示标签、单位、统计期、影响资质、口径帮助和敏感提示。
- 数值字段允许输入 `0`，布尔字段提供“是 / 否 / 不清楚”，未选择不等同“否”。
- 列表数据使用逐项输入方式，并提示权属、状态和材料仍需核验。
- 保存时显示字段级错误，不清空其他合法输入。
- 保存成功后重新获取缺失字段；表单内容应随补充结果变化。

## 12. 协议弹窗与登录

弹窗内容：

- 标题“发起诊断前请阅读”或“登录查看报告前请阅读”。
- 企业数据处理、报告保存和 Demo 登录说明。
- 用户协议、隐私政策、免责声明链接及版本。
- “我已阅读并同意上述文件”复选框。
- 主操作和“暂不进行”次操作。

交互顺序：

```text
打开弹窗 → 复选框未勾选
未勾选确认 → 留在弹窗并提示
关闭或暂不进行 → 返回原页面，不登录
勾选并确认 → 建立会话 → 创建诊断或加载报告
```

- 登录中和创建诊断中使用不同提示，按钮保持禁用。
- 登录失败时提示“登录未完成，尚未创建诊断”。
- 创建诊断失败时说明会话与诊断的不同状态，并允许重试。
- 报告 Tab 的登录按钮只打开协议弹窗；已有有效会话时直接加载列表。

## 13. 诊断进度

处理内容依次显示：准备企业数据、检查数据完整性、执行四类资质规则、整理证据与行动、生成报告。

- `pending` 显示等待处理。
- `processing` 显示当前处理内容和已完成项。
- `ready` 显示“报告已生成”和查看报告按钮。
- `failed` 显示安全的失败原因和重新发起入口。
- 页面回到前台时立即刷新状态；离开页面不取消服务端诊断。
- 不展示虚假的精确耗时承诺。

## 14. 诊断报告

信息顺序：

1. 企业、报告生成时间、规则核验日期和 Demo 标签。
2. 预评估免责声明。
3. 四类资质结果卡：状态、摘要、主要缺口和人工核验数量。
4. 当前资质的关键条件、规则版本、适用地域和数据完整度。
5. 证据链、缺口与行动、联系顾问入口。

页面只显示服务端报告结果，不在前端重新计算规则。人工核验使用“需人工核验”，不与“已达到”使用相同表现。不适用状态说明具体地域或主体原因。

## 15. 证据链

- 按资质分组，优先展示未达到、缺少数据和需人工核验项。
- 单项顺序为：条件、政策要求、企业数据、单位和期间、来源、判断、说明、建议行动。
- 缺失值显示“未提供”，不显示为 `0`。
- 派生比例展示原始分子、分母和计算说明。
- 数据冲突时展示各来源和观察时间。

## 16. 缺口与行动

- 支持查看全部、高优先、需补数据和需人工核验内容。
- 缺口卡展示标题、重要性、关联规则、影响资质和优先级。
- 行动卡展示建议动作、建议材料、先后顺序和是否建议顾问。
- 无明确缺口时提示：“未发现可自动识别的明确缺口；定性条件及主管部门审核仍需核验。”

## 17. 报告 Tab

| 页面状态 | 主要内容 | 主操作 |
| --- | --- | --- |
| 未登录 | 解释登录只用于查看保存报告 | 登录查看报告，先打开默认未勾选的协议弹窗 |
| 无报告 | 尚未发起诊断 | 开始预评估 |
| 进行中 | 企业、创建时间、当前处理信息 | 查看进度 |
| 已完成 | 企业、四类结果摘要、生成时间 | 查看报告 |
| 失败 | 企业、失败信息 | 重新发起或查看详情 |

进入 Tab 时只检查已有会话；无会话时直接显示未登录状态。

## 18. 我的 Tab 与法律页

- 游客始终看到使用说明、隐私政策、用户协议和免责声明。
- 已登录时显示 Demo 会话状态和“退出登录”。
- 退出前二次确认；成功后清除本地会话和经营数据草稿。
- 法律页展示标题、版本、生效日期和正文；协议弹窗链接打开对应文件。

## 19. 联系顾问

字段包括联系人、手机号、企业、咨询方向、备注和独立隐私同意。

- 不强制登录，不强制微信手机号授权。
- 独立隐私复选框每次进入页面默认未勾选。
- 提交中禁用重复点击。
- 字段错误使用行内提示，网络错误保留用户输入。
- 成功只显示“咨询需求已提交”和返回操作，不显示“顾问已接单”。

## 20. 适配与操作反馈

- 关键触控目标建议不小于 44px，并保持足够间距。
- 输入控件使用可见标签、单位和错误说明，不只依赖占位文字。
- 长企业名和政策名允许换行，核心内容不横向滚动。
- 数字输入使用合适键盘，页面滚动后仍可访问当前输入和提交按钮。
- 请求中按钮显示处理中并防止重复提交。
- 成功和失败除轻提示外，还提供页面级反馈。

## 21. 交互验收要点

- 冷启动无登录、授权或协议弹窗。
- 三个 Tab、普通页面和返回路径正确。
- 动态表单只展示缺失项，`0` 和“否”正确显示。
- 协议首次和重开均未勾选，拒绝后仍可浏览。
- 诊断进度可恢复，完成后可进入四类报告。
- 证据、缺口、行动和免责声明信息层级清楚。
- 报告 Tab 的未登录、无报告、进行中、完成和失败状态可理解。
- 顾问独立同意默认未勾选，成功文案准确。
- 页面不显示内部堆栈、会话 token 或敏感草稿。
